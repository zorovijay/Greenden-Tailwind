# GreenDen – Plant Store Website 🌿

GreenDen is a responsive plant store website developed using **HTML and Tailwind CSS**. The website features a clean, modern design inspired by nature, providing users with an attractive and user-friendly browsing experience for indoor plants and greenery.

## 🌱 Features

- **Home Page:** A welcoming landing page with an attractive layout.
- **Product Section:** Displays plants and related products in an organized format.
- **Responsive Design:** Adapts to different screen sizes using Tailwind CSS utility classes.
- **Modern UI:** Clean layouts, consistent spacing, and nature-inspired styling.
- **Navigation Bar:** Simple navigation for easy access to website sections.
- **Contact Section:** Provides a way for visitors to find contact information.

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS

The main objective of this project is to develop a visually appealing and responsive plant store website while gaining practical experience in HTML and Tailwind CSS.
